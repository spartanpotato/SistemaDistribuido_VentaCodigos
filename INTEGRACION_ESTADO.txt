🚀 INSTALACIÓN RÁPIDA

1. Instalar dependencias
   cd frontend
   npm install

2. Verificar backend
   cd backend
   python app.py
   # Debe estar escuchando en http://localhost:5000

3. Iniciar frontend
   cd frontend
   npm start
   # Abre http://localhost:3000

4. Probar integración
   - Buscar juego en GamesPage
   - Agregar al carrito
   - Click en checkout
   - Completar formulario
   - Ver confirmación

⚠️ IMPORTANTE

1. Backend debe estar en http://localhost:5000
2. Redis debe estar corriendo (para carrito)
3. PostgreSQL debe estar disponible
4. RabbitMQ debe estar disponible (async jobs)

Para desarrollo local:
  - Editar .env si backend está en otro puerto
  - Verificar CORS en Flask app.py
  - Ver console del navegador para errores
